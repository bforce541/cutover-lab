# Cutover Lab

Rehearse a finance-report migration using TLC yellow taxi records. The switch requires a current, independently computed match at month, day, and pickup-zone grain. Read through the approved provider after switching. On failure, read and verify the current source or return unavailable.

FastAPI owns checks, approval and routing. DuckDB reads the original files. The local candidate runs independently in DuckDB. Databricks and BigQuery aggregate their dedicated row-level tables. React renders the review and its query evidence.
